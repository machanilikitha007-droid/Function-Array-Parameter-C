# Function Using an Array in C

This program demonstrates passing an array to a function and displaying
its elements.

## File

array_function.c

## Concepts Used

- Function definition
- Array as function parameter
- Function call
- for loop

## How to Run

gcc array_function.c -o array_function
./array_function

## Sample Output

Array Elements: 10 20 30 40 50
